A make.fun entry for the **One Line, No Deadline Met** bounty: one line
that excuses a missed deadline — built on one real office detail, the
laptop that picks the exact hour of the deadline to update, restart
twice, and then ask you to rate the experience.

## The joke

> My deadline was 5 p.m. My laptop picked 5 p.m. to update, restart twice, and ask me to rate the experience.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single joke to `/output/entry.txt` (UTF-8,
one line, inside the 1–200 character gate).

```sh
python3 main.py
cat /output/entry.txt
```
